# Employee Management System

## Project Overview
The Employee Management System is a Python-based console application that helps manage employee records. It allows users to add, view, search, update salaries, and delete employee details through a menu-driven interface.

## Features
- **Add Employee:** Add new employees with ID, name, department, and salary.
- **View Employees:** Display all employee records.
- **Search Employee:** Find an employee using their ID.
- **Update Salary:** Modify an employee's salary.
- **Delete Employee:** Remove an employee record.
- **Input Validation:** Validate employee ID, name, department, and salary.
- **Duplicate ID Prevention:** Prevent adding employees with an existing ID.
- **Error Handling:** Handle invalid numeric inputs.
- **Menu-Driven Interface:** Select operations using menu options.
