# Sales Data Analysis and Visualization

## Project Overview

The Sales Data Analysis and Visualization project uses Python to analyze sales data stored in a CSV file. It calculates total revenue, compares revenue across products and regions, identifies the highest-performing product and region, and presents the results using bar charts.

## Project Objectives

- Analyze sales data using Python.
- Calculate total sales revenue.
- Compare revenue generated by different products.
- Analyze revenue across different regions.
- Identify the product and region generating the highest revenue.
- Visualize sales performance using charts.

## Technologies Used

- **Python** — Data processing and calculations.
- **Pandas** — Reading, grouping, and analyzing CSV data.
- **Matplotlib** — Creating bar charts for visualization.
- **CSV** — Storing sales records.

## Dataset Description

The project uses a CSV file containing sales records with the following columns:

 Column          Description 

 Product       Name of the product sold 
 Quantity      Number of units sold 
 UnitPrice     Price per unit 
 Region        Region where the sale occurred

## Features

### 1. Calculate Total Sales

Calculates the revenue for each record by multiplying quantity by unit price.

**Formula:**

Total Sales = Quantity × Unit Price

### 2. Calculate Total Revenue

Calculates the total revenue generated across all sales records.

### 3. Revenue by Product

Groups sales by product and calculates the revenue generated by each product.

### 4. Revenue by Region

Groups sales by region and compares regional sales performance.

### 5. Identify Top Performers

Identifies the product and region with the highest revenue.

### 6. Data Visualization

Creates bar charts to display revenue by product and region, including chart titles, axis labels, and revenue values.
